## 1. Pre-installation

### Boot the live ISO

1. Download the latest Arch ISO from `archlinux.org/download`.
2. Flash to USB: `dd bs=4M if=archlinux-*.iso of=/dev/sdX status=progress oflag=sync`
3. Boot, select **Arch Linux install medium**.

### Connect to the internet

```bash
# Ethernet — usually works immediately
ip link

# WiFi
iwctl
  station wlan0 scan
  station wlan0 get-networks
  station wlan0 connect "SSID"
  exit

ping archlinux.org
```

### Update the system clock

```bash
timedatectl set-ntp true
```

## 2. Disk partitioning

### Layout (adapt device names to your system)

| Device | Mount     | Size        | Filesystem | Notes                  |
|--------|-----------|-------------|------------|------------------------|
| sdb1   | /boot     | 1 GB        | FAT32      | EFI system partition   |
| sdb2   | /         | 60 GB       | ext4       | SSD root               |
| sdb3   | /home     | remaining   | ext4       | SSD home               |
| sda1   | /data     | full disk   | ext4       | HDD bulk storage       |

> `sdb` = SSD (primary), `sda` = HDD (secondary).  
> Adjust if your drives appear as `nvme0n1` etc.

### Partition with fdisk

```bash
# SSD
fdisk /dev/sdb
# g  → new GPT
# n  → +1G  → type EFI (t → 1)
# n  → +60G → type Linux filesystem
# n  → remaining → type Linux filesystem
# w

# HDD
fdisk /dev/sda
# g → n → full disk → w
```

### Format

```bash
mkfs.fat -F32 /dev/sdb1
mkfs.ext4 /dev/sdb2
mkfs.ext4 /dev/sdb3
mkfs.ext4 /dev/sda1
```

### Mount

```bash
mount /dev/sdb2 /mnt
mkdir -p /mnt/{boot,home,data}
mount /dev/sdb1 /mnt/boot
mount /dev/sdb3 /mnt/home
mount /dev/sda1 /mnt/data
```

## 3. Base install

```bash
# Optimise mirrors first (Europe example — change countries as needed)
reflector --country "France,Germany,Netherlands,United Kingdom" \
          --protocol https --latest 10 --sort rate \
          --save /etc/pacman.d/mirrorlist

# Install base system + both kernels
pacstrap -K /mnt \
    base base-devel \
    linux-lts linux-lts-headers \
    linux linux-headers \
    linux-firmware \
    intel-ucode \
    networkmanager \
    sudo \
    vim \
    git \
    zram-generator

# Generate fstab
genfstab -U /mnt >> /mnt/etc/fstab
```

## 4. Bootloader (systemd-boot, dual-kernel)

```bash
arch-chroot /mnt

# Install systemd-boot to EFI partition
bootctl install

# Loader config — default to LTS, 5s timeout
cat > /boot/loader/loader.conf << 'EOF'
default 2026-*_linux-lts.conf
timeout 5
console-mode max
editor no
EOF
```

Boot entries are auto-generated by `kernel-install` hooks when you install the
kernels.  Verify after install:

```bash
ls /boot/loader/entries/
# Should show both a linux-lts entry and a linux entry

# Confirm LTS is default
cat /boot/loader/loader.conf
```

### Add kernel parameters to the LTS entry

> Replace the entry filename with the one generated on your system.

```bash
LTS_CONF=$(ls /boot/loader/entries/*linux-lts.conf | head -1)

# Stability + performance params for Intel HD 5500 (Broadwell)
sed -i '/^options / s/$/ quiet loglevel=3 nowatchdog nmi_watchdog=0 mitigations=auto i915.enable_psr=0/' \
    "$LTS_CONF"
```

`i915.enable_psr=0` disables Panel Self Refresh, which is the primary cause of
display freezes on Broadwell graphics.

## 5. System configuration

```bash
# Timezone
ln -sf /usr/share/zoneinfo/Africa/Casablanca /etc/localtime   # adjust as needed
hwclock --systohc

# Locale
sed -i 's/#en_US.UTF-8/en_US.UTF-8/' /etc/locale.gen
locale-gen
echo "LANG=en_US.UTF-8" > /etc/locale.conf

# Hostname
echo "archbox" > /etc/hostname
cat > /etc/hosts << 'EOF'
127.0.0.1   localhost
::1         localhost
127.0.1.1   archbox.localdomain archbox
EOF

# Root password
passwd

# Create user
useradd -m -G wheel -s /bin/bash achma
passwd achma
sed -i 's/# %wheel ALL=(ALL:ALL) ALL/%wheel ALL=(ALL:ALL) ALL/' /etc/sudoers

# Enable NetworkManager
systemctl enable NetworkManager

# Exit chroot and reboot
exit
umount -R /mnt
reboot
```

## 6. KDE Plasma (X11)

After first boot, log in as your user and install the desktop:

```bash
sudo pacman -Syu

sudo pacman -S --needed \
    xorg xorg-server \
    plasma-meta \
    kde-applications-meta \
    appmenu-gtk-module \
    libdbusmenu-gtk2 \
    libdbusmenu-gtk3 \
    plasma-browser-integration \
    xdg-desktop-portal-kde \
    gmenudbusmenuproxy
```

> `appmenu-gtk-module`, `libdbusmenu-gtk2`, and `gmenudbusmenuproxy` are required
> for the KDE Global Menu widget to work with GTK2/GTK3 apps (Firefox, Thunar, etc.).

## 7. SDDM display manager

```bash
sudo pacman -S --needed sddm sddm-kcm

sudo systemctl enable sddm
```

### Force X11 and Plasma (X11) as default session

```bash
# Create the X11 Plasma session desktop file
sudo mkdir -p /usr/share/xsessions
sudo tee /usr/share/xsessions/plasmax11.desktop << 'EOF'
[Desktop Entry]
Type=XSession
Exec=/usr/bin/startplasma-x11
TryExec=/usr/bin/startplasma-x11
DesktopNames=KDE
Name=Plasma (X11)
Comment=Plasma by KDE (X11 backend — stable on Intel HD 5500)
EOF

# Force SDDM to use X11
sudo mkdir -p /etc/sddm.conf.d
sudo tee /etc/sddm.conf.d/10-x11.conf << 'EOF'
[General]
DisplayServer=x11

[X11]
ServerArguments=-nolisten tcp -background none
EOF

# Set last-used session to Plasma X11 (so SDDM defaults to it)
sudo mkdir -p /var/lib/sddm
sudo tee /var/lib/sddm/state.conf << 'EOF'
[Last]
Session=plasmax11
User=achma
EOF
```

> **Why X11 instead of Wayland?**  
> The Intel HD 5500 (Broadwell) has known compositor hangs under Wayland/KWin.
> X11 is stable on this hardware. Once upstream i915 Wayland stability improves
> this can be revisited.

## 8. Post-install optimisation script

Run **as root** after first login:

```bash
sudo bash scripts/arch-optimize-continue.sh
```

See [`scripts/arch-optimize-continue.sh`](scripts/arch-optimize-continue.sh) for the full source.

### What it does

| Step | Change | Reason |
|------|--------|--------|
| Packages | Installs `tlp`, `irqbalance`, `thermald`, `earlyoom`, `reflector`, etc. | Core laptop tooling |
| Sysctl | `vm.swappiness=10`, inotify limits, network buffers | 16 GB RAM — avoid swap; KDE file watchers |
| IO scheduler | `none` for SSD (`sdb`), `bfq` for HDD (`sda`) | Flash storage needs no reordering; BFQ improves HDD latency |
| fstab | `relatime` → `noatime` on ext4 (SSD) | Reduces SSD write amplification |
| THP | `always` → `madvise` | Better for desktop workloads |
| Journal | Capped at 100 MB, compressed | Keeps `/var` tidy |
| TLP | Full AC/BAT config for i5-5200U | See table below |
| Low-battery udev | Auto-suspend at ≤10% | Old battery protection — prevents hard shutdown |
| Boot delays | Disables `NetworkManager-wait-online` | Removes ~25s boot penalty |
| Mirrors | `reflector` — fastest EU HTTPS mirrors | Faster `pacman -Syu` |
| Pacman | `ILoveCandy`, `VerbosePkgLists`, 10 parallel downloads | Quality-of-life |

### TLP AC vs Battery profile

| Parameter | AC | Battery |
|-----------|-----|---------|
| CPU governor | `performance` | `powersave` |
| CPU turbo | ON | OFF |
| CPU max freq | 2700 MHz | 800 MHz |
| HWP policy | `performance` | `power` |
| Disk APM | 254 (off) | 1 (aggressive) |
| PCIe ASPM | `default` | `powersupersave` |
| WiFi power save | off | on |
| USB autosuspend | off | on |
| Platform profile | `performance` | `low-power` |

## 9. Freeze-fix script (Intel HD 5500)

Run **as root** on first boot into the new system:

```bash
sudo bash scripts/arch-freeze-fix.sh
```

See [`scripts/arch-freeze-fix.sh`](scripts/arch-freeze-fix.sh) for the full source.

### What it does

| Fix | Detail |
|-----|--------|
| `i915.enable_psr=0` | Added to LTS (and regular linux) boot entry — disables Panel Self Refresh |
| `i915 modprobe` | `/etc/modprobe.d/i915.conf` — `enable_psr=0 enable_fbc=0` persistent across kernel updates |
| Live apply | `echo 0 > /sys/module/i915/parameters/enable_psr` — no reboot needed for current session |
| Magic SysRq | `kernel.sysrq=1` — enables `Alt+SysRq+REISUB` safe reboot during a freeze |
| zram | `zram-generator` with `ram/2`, `zstd` — prevents OOM-triggered freezes |

> **FBC (Framebuffer Compression)** is also disabled. On Broadwell it can cause
> visual artifacts in addition to PSR.  
> **Magic SysRq REISUB**: hold Alt+SysRq, then press R E I S U B one at a time with
> a 1-second pause between each — safe emergency reboot without filesystem corruption.

## 10. AC performance + GTK global app menu

Run **as root** after the freeze-fix reboot:

```bash
sudo bash scripts/arch-ac-appmenu-fix.sh
```

See [`scripts/arch-ac-appmenu-fix.sh`](scripts/arch-ac-appmenu-fix.sh) for the full source.

### TLP AC tightening

| Parameter | Before | After | Reason |
|-----------|--------|-------|--------|
| `CPU_SCALING_MIN_FREQ_ON_AC` | 500 MHz | 1000 MHz | Avoids scheduler ramp-up latency on AC |
| `PCIE_ASPM_ON_AC` | `default` | `performance` | No PCIe link-power throttling on AC |
| `USB_AUTOSUSPEND` | 1 | 0 | AC-primary machine — peripherals always active |

### GTK Global Menu wiring

Two config files are written so GTK2/GTK3 apps export their menus to the KDE
Global Menu widget:

| File | Purpose |
|------|---------|
| `~/.config/plasma-workspace/env/gtk-global-menu.sh` | Sourced by `startplasma-x11` at login — sets `GTK_MODULES` and `GTK3_MODULES` |
| `~/.config/environment.d/gtk-global-menu.conf` | systemd user environment — covers apps launched outside the KDE session |

> **GTK4 limitation**: GTK4 removed `dbusmenu` support entirely. Global menu will
> not work for GTK4 apps (~5% of apps). Qt/KDE apps and GTK2/GTK3 apps (Firefox,
> Thunar, etc.) all work after re-login.

### Google Chrome

`~/.config/chrome-flags.conf` is created with:

```
--use-system-title-bar
--ozone-platform-hint=x11
```

This hands window decoration to KWin, making Chrome's menu bar visible to
`gmenudbusmenuproxy`.

## 11. Post-reboot cleanup

After the reboot following steps 9–10:

```bash
sudo bash scripts/arch-post-reboot-fix.sh
```

See [`scripts/arch-post-reboot-fix.sh`](scripts/arch-post-reboot-fix.sh) for the full source.

Fixes three boot-log warnings:

| Warning | Fix |
|---------|-----|
| `TLP: value 0 out of range 300-900` | Removes invalid `INTEL_GPU_*_FREQ` lines — HD 5500 range is 300–900 MHz; TLP manages GPU via energy policy |
| `failed to load regulatory.db` | Installs `wireless-regdb`, sets WiFi regulatory domain to `MA` (Morocco) |
| SDDM falling back to Wayland | Re-locks `/var/lib/sddm/state.conf` to `Session=plasmax11` |

## 12. Verification checklist

After all scripts and final reboot:

```bash
# Kernel — should show linux-lts
uname -r

# Session — must be empty (confirms X11, not Wayland)
echo $WAYLAND_DISPLAY

# PSR disabled
cat /sys/module/i915/parameters/enable_psr       # → 0

# FBC disabled
cat /sys/module/i915/parameters/enable_fbc       # → 0

# Swappiness
cat /proc/sys/vm/swappiness                      # → 10

# IO scheduler SSD
cat /sys/block/sdb/queue/scheduler               # → none [none]

# IO scheduler HDD
cat /sys/block/sda/queue/scheduler               # → [bfq]

# THP
cat /sys/kernel/mm/transparent_hugepage/enabled  # → [madvise]

# Services
systemctl is-active tlp irqbalance thermald earlyoom

# zram
zramctl

# GTK modules (after re-login)
echo $GTK_MODULES      # → appmenu-gtk-module
echo $GTK3_MODULES     # → appmenu-gtk-module

# SysRq
cat /proc/sys/kernel/sysrq                       # → 1
```

### Add the KDE Global Menu widget

1. Right-click the top panel → **Add Widgets**
2. Search for **Global Menu** → drag to panel
3. Open Firefox — the File/Edit/View menu bar should appear in the panel

## Script inventory

| Script | When to run | Purpose |
|--------|-------------|---------|
| `scripts/arch-optimize-continue.sh` | First login (root) | Core system optimisations |
| `scripts/arch-freeze-fix.sh` | First boot (root) | Intel HD 5500 freeze fixes |
| `scripts/arch-ac-appmenu-fix.sh` | After freeze-fix reboot (root) | AC perf tuning + GTK global menu |
| `scripts/arch-post-reboot-fix.sh` | After appmenu reboot (root) | Clean up boot warnings |

### Recommended run order

```
install → reboot → arch-optimize-continue.sh
                 → arch-freeze-fix.sh
        → reboot → arch-ac-appmenu-fix.sh
        → reboot → arch-post-reboot-fix.sh
        → re-login → verify checklist
```
